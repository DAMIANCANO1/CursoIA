# CursoIA

Repositorio educativo/técnico para prácticas y desarrollo de proyectos con IA. Actualmente incluye una aplicación frontend en `InMaterial` construida con React + Vite.

## Características principales

- Base para contenidos y ejercicios del curso de IA.
- Aplicación web con React para experimentar interfaces y flujos.
- Estructura simple para iterar en ejemplos y prácticas.

## Requisitos previos

- Node.js 20+ (recomendado LTS)
- npm 10+
- Git

## Instalación

```bash
git clone https://github.com/DAMIANCANO1/CursoIA.git
cd CursoIA/InMaterial
npm ci
```

## Uso

Iniciar entorno de desarrollo:

```bash
npm run dev
```

Compilar para producción:

```bash
npm run build
```

Previsualizar compilación:

```bash
npm run preview
```
